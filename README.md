# Movies Portfolio 🎬

[![Live Showcase](https://img.shields.io/badge/Live-Showcase-blueviolet?style=for-the-badge)](https://movie-portfolio-react.vercel.app/)
[![Vercel Deployment](https://img.shields.io/badge/Deployed%20with-Vercel-black?style=for-the-badge&logo=vercel)](https://movie-portfolio-react.vercel.app/)

A modern, responsive movie discovery application built with **React 19**, **Vite 8**, and **Supabase**. This project is specifically designed as a learning sandbox to practice configuring **CI/CD pipelines from scratch**, implementing serverless API endpoints, and deploying to **Vercel**.

---

## 🎯 Project Purpose & CI/CD Focus
This project serves as a hands-on exercise for configuring and understanding CI/CD concepts:
* **CI/CD from Scratch:** Designed to implement, test, and troubleshoot deployment workflows.
* **Vercel Deployment:** Automatically deploys production-ready builds on pushes to the repository.
* **Pre-deployment Verification:** Includes local build checks, TypeScript compilation, linting, and automated unit testing.

---

## 🛠️ Technology Stack
* **Framework:** React 19
* **Build Tool:** Vite 8
* **Language:** TypeScript
* **Styling:** Tailwind CSS 3 (with PostCSS & Autoprefixer)

* **Linting:** ESLint

## 🏗️ Design Patterns & Architecture
The project applies clean code architecture and standard frontend/backend design patterns:

### 1. Database Persistence (Supabase Integration)
User preferences (like favorite movies) are persisted in a Supabase PostgreSQL database. This allows users' favorites to be retained across browser sessions.
* **Table Schema (`favorite_movies`):**
  ```sql
  create table favorite_movies (
    id bigint generated by default as identity primary key,
    movie_id bigint unique not null,
    is_favorite boolean default true,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
  );
  ```

### 2. Serverless API Layer
Instead of calling the database or third-party APIs directly from the client, requests are routed through Vercel Serverless Functions. This protects API keys and keeps database connection logic secure:
* **Get Favorites List:** `/api/favorites/list` retrieves the user's favorited movie IDs.
  * **File:** [api/favorites/list.ts](file:///c:/Users/alexander.zapata/Documents/Personal%20Projects/movies-portfolio/api/favorites/list.ts)
* **Toggle Favorite Status:** `/api/favorites/toggle` inserts or deletes a favorite movie record.
  * **File:** [api/favorites/toggle.ts](file:///c:/Users/alexander.zapata/Documents/Personal%20Projects/movies-portfolio/api/favorites/toggle.ts)
* **AI Critic Summary:** `/api/summary` calls the Vercel AI SDK to get a consensus summary of a movie using Google's `gemini-2.5-flash` model.
  * **File:** [api/summary.ts](file:///c:/Users/alexander.zapata/Documents/Personal%20Projects/movies-portfolio/api/summary.ts)

### 3. Frontend Architecture
* **Context Provider Pattern:** Manages global state for movies, loading indicators, and error tracking across components without prop-drilling.
  * **File:** [MovieContext.tsx](file:///c:/Users/alexander.zapata/Documents/Personal%20Projects/movies-portfolio/src/context/MovieContext.tsx)
* **Custom Hooks & Debouncing:** Encapsulates complex logic for search delays. The search input uses a 500ms debounce cleanup to prevent unnecessary TMDB API calls while typing.
  * **File:** [useMovieSearch.ts](file:///c:/Users/alexander.zapata/Documents/Personal%20Projects/movies-portfolio/src/hooks/useMovieSearch.ts)
* **Service Layer Pattern:** Abstracts API communication logic away from React components, providing clean, reusable methods for fetching and searching movies.
  * **File:** [movie.service.ts](file:///c:/Users/alexander.zapata/Documents/Personal%20Projects/movies-portfolio/src/services/movie.service.ts)
* **API Mocking & Spy Testing:** Ensures testing isolation by using Vitest spies (`vi.spyOn`) and static JSON mock data to verify API services without making real network requests.
  * **File:** [movie.service.test.ts](file:///c:/Users/alexander.zapata/Documents/Personal%20Projects/movies-portfolio/src/tests/services/movie.service.test.ts)

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js and `pnpm` installed.

### Installation
```bash
# Clone the repository
git clone <repository-url>

# Install dependencies
pnpm install
```

### Environment Setup
Create a `.env` file in the root directory and add the required configuration variables:

```env
# TMDB Configs
VITE_TMDB_IMAGE_BASE_URL="https://image.tmdb.org/t/p/w500/"
VITE_TMDB_BASE_API_URL="https://api.themoviedb.org/3"
VITE_TMDB_KEY=your_tmdb_api_key_here

# Supabase Credentials (for Favorites endpoints)
SUPABASE_URL=your_supabase_url_here
SUPABASE_ANON_KEY=your_supabase_anon_key_here

# Google Gemini API Key (for AI Critique consensus summary)
GOOGLE_GENERATIVE_AI_API_KEY=your_google_ai_key_here
```

### Available Scripts
```bash
# Run local development server (using Vercel Dev to support Serverless functions locally)
pnpm vercel dev

# Or run Vite standalone server (Note: API functions will not resolve in standalone)
pnpm dev

# Run Vitest test suite
pnpm test

# Run ESLint check
pnpm lint

# Build the project (TypeScript check + Vite build)
pnpm build
```
